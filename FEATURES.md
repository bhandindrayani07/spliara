# Spliara — Split smart.

## Project Overview

Spliara is a shared-expense management platform that helps friends, roommates, families and travel groups manage shared expenses, split bills fairly, track outstanding balances and record settlements in one place.

The platform aims to make group expense management simple, transparent and convenient.

## User Roles

1. **Registered User:** Creates an account, joins groups and participates in expense sharing.
2. **Group Member:** Views group expenses, adds shared expenses, participates in bill splitting and checks balances.
3. **Group Creator:** Creates groups, manages group members and oversees shared expenses.

## MVP Features

### 1. Authentication
- User signup, login and logout.
- Secure password hashing.
- User profile management.

### 2. Group Management
- Create, edit and delete expense groups.
- Add and manage group members.
- View group details and member lists.

### 3. Shared Expense Management
- Add, edit and delete shared expenses.
- Select who paid for an expense.
- Add expense descriptions, dates and categories.
- View group expense history.

### 4. Expense Splitting
- Split expenses equally among group members.
- Split expenses using custom amounts.
- Calculate each member's share.
- Validate that split amounts equal the total expense.

### 5. Balance Management
- Calculate who owes whom.
- Display outstanding balances.
- Track amounts paid and amounts owed.

### 6. Settlements
- Record repayments between group members.
- Update balances after settlements.
- View settlement history.

### 7. Search and Filters
- Search expenses by description.
- Filter expenses by date, category and payer.
- View expenses group-wise.

### 8. Group Dashboard
- View total group expenses.
- View individual member balances.
- See recent group activities.
- Access groups, expenses and settlements.

## Technology Stack

- Frontend: React.js and CSS.
- Backend: Node.js and Express.js.
- Database: PostgreSQL.
- Authentication: JWT and bcrypt.
- API Testing: Postman.
- Version Control: Git and GitHub.
- Deployment: Vercel and a suitable backend hosting provider.

Build a responsive, secure and user-friendly expense-splitting platform that simplifies group expense tracking, fair bill splitting and settlement management, with a reusable backend that can later support a mobile application.
