# Spliara

### Split smart.

Spliara is a shared-expense management platform that helps friends, roommates, families and travel groups manage shared expenses, split bills fairly, track outstanding balances and record settlements in one place.

## Features

- **User Authentication:** Secure signup and login.
- **Group Management:** Create groups and manage members.
- **Expense Tracking:** Add, edit and delete shared expenses.
- **Flexible Splitting:** Split bills equally or using custom amounts.
- **Balance Management:** Track who owes whom and how much.
- **Settlements:** Record repayments and view settlement history.
- **Search and Filters:** Find expenses by date, category, payer or group.
- **Dashboard:** View group expenses, outstanding balances and recent activities.

## Technology Stack

- Frontend: React.js and CSS
- Backend: Node.js and Express.js
- Database: PostgreSQL
- Authentication: JWT and bcrypt
- API Testing: Postman
- Version Control: Git and GitHub
- Deployment: Vercel and backend hosting provider

## Project Goals

Spliara aims to make shared expense management simple and transparent.

- Reduce confusion when splitting group expenses.
- Keep track of payments between group members.
- Make expense sharing easier for roommates, friends, and travel groups.
- Provide a clear view of group balances.
